# ЦОТАН (Tsotan Textile) — concept (Nomad Web Studio)
Idea: Цотангийн бүх зураг дээр ширээний ирмэгт байдаг **туузан метр (см хэмжүүр)** нь хуудасны **хэмжээ, үнэ, гүйлгэлтийг харуулах шугам** болно. Гол мессеж: "Монгол хээ, хүссэн хэмжээгээр".
Live thing: Бүтээлгийн тооцоолуур — ширээний урт/өргөн + унжилт → тохирох хэмжээ, бэлэн 145×220 таарах эсэх, хээ/өнгөтэй дээрээс харсан SVG зураг, захиалгын мессеж (хуулах / Messenger / залгах).
Color: --cotton #f4f1ea (суурь) · --paper #fbfaf6 · --ink #211c18 · --line rgba(33,28,24,.14) · --teal #1e5a53 (үйлдлийн өнгө) · --clay #b0533a · --ochre #c4922c · --cobalt #2c4a8f (зөвхөн хээний өнгө сонголтод)
Type: Cormorant Garamond 500–700 (гарчиг, үнэ, wordmark; Ү Ө ₮ шалгасан) · Geologica 300–600 (бичвэр, UI, tabular тоо)
Spacing: 8px алхам; section хооронд 128–176px desktop / 88px mobile; margin clamp(16px,4vw,56px)
Radius: зураг 6px, товч 999px биш — 4px; шугам 1px
Motion: header доорх см шугам дээр гүйлгэлтийн заагч (0–220 см); hero зурагны хажуугийн шугам зурагдана; хэсгүүд 16px доороос (IntersectionObserver-ийн ажиглаж буй элемент дээр clip-path ХЭРЭГЛЭХГҮЙ); reduced-motion үед бүгд хөдөлгөөнгүй.
Images: захиалагчийн илгээсэн 8 зураг + FB хуудасны бодит зураг (Higgsfield upscale, AI дахин зураагүй). Дүрийн (Grinch, Stitch, Spider-Man г.м) зурагтай уутнуудыг зохиогчийн эрхийн эрсдэлээс болж оруулаагүй.
Logo: албан лого байхгүй тул түр wordmark "ЦОТАН" + өлзий хээний тэмдэг.
