# ЦОТАН (Tsotan Textile) — v2 concept (Nomad Web Studio)
Лавлагаа: хэрэглэгчийн илгээсэн NEXA agency бичлэг — хар хүрээ (bezel), зүүн sidebar дээр босоо лого, дугуй булантай том panel-ууд, pill навигаци, panel-ын буланд "хазагдсан" notch товч, кино мэт hero, хөвөгч объект.
Idea: Цотангийн зураг бүрт байдаг **туузан метр** → sidebar-ын **босоо см шугам** гүйлгэлтийг 0–220 см-ээр хэмжинэ (lerp-ээр зөөлөн, тухайн хэсгийн нэртэй). Hero дээр **4 шагай** хөвнө — "дөрвөн бэрх" (морь, тэмээ, хонь, ямаа гэсэн 4 өөр тал буусан азтай буулт). Утсан дээр 4-үүлээ гарчгийн доор харагдана.
Live thing: бүтээлгийн тооцоолуур (ширээний урт/өргөн → бэлэн 145×220 таарах эсэх, хээ/өнгөтэй SVG, захиалгын мессеж).
Color: --bez #0e1513 (хүрээ) · --bez2 #16201d · --cotton #f4f1ea · --ink #211c18 · --teal #1e5a53 · --clay #b0533a · --ochre #c4922c (үйлдлийн тойрог) · --cobalt #2c4a8f. Өнгөт хэсгүүдийн дэвсгэрийг Higgsfield зургийн дэвсгэрээс авсан: #114040 · #a3412a · #b87e24 · #153884.
Type: Montserrat 800/900 (гарчиг, ТОМ ҮСГЭЭР, giant үгс) · Geologica 300–600 (бичвэр). Ү Ө ₮ шалгасан.
Radius: panel 28px (утсанд 22), карт 20–22, pill 999.
Motion: GSAP 3.12.5 + ScrollTrigger + Lenis 1.1.13 (CDN). Intro: hero clip-path нээгдэнэ, гарчгийн мөр доороос; шагай float + хулганы parallax; hero бичлэг scroll-оор томорно; statement үг бүр scrub-аар тодорно; 4 өнгөт scene sticky-гээр давхарлана (дараагийнх нь дээрээс гулсахад өмнөх нь .95 болж, дэвсгэр нь дараагийн өнгө рүү уусна, агуулга нь бүдгэрнэ — хар/brightness filter хэрэглэхгүй), giant үг хэвтээ гүйнэ; бүтээгдэхүүний галерей pin + хэвтээ scrub (desktop), утсанд scroll-snap. GSAP ачаалагдахгүй эсвэл reduced-motion үед бүх агуулга хөдөлгөөнгүй харагдана (CSS-ээр юу ч нуухгүй).
Images: Higgsfield gpt_image_2_5 — hero (хийсэж буй хээтэй даавуу), шагай (gpt_image_2_5 transparent, 4 талыг нэг зурагт гаргаж тус тусад нь тайрсан: shagai-mori/temee/honi/yamaa); kling3_0 pro 10s hero бичлэг (start=end → тасралтгүй давталт).
3D cutout (дэвсгэргүй, хөвөгч): 4 scene (cut-*.webp), бүтээгдэхүүний 9 карт (p-*.webp), захиалгат ажлын 3 зураг (c-*.webp). Бүгд захиалагчийн бодит FB зургийг reference болгож gpt_image_2_5-аар 3D студийн зураг болгоод remove_background хийсэн. Lexus цүнхний лого = бодит зургаас авсан хэвлэлийг хоосон цүнхэн дээр буулгасан (AI лого зураагүй).
Карт/зургийн ард өнгөт дэвсгэр (--c: teal/ochre/cobalt/clay ээлжилнэ) + бүдэг том үг (.gw); объект CSS bob-оор хөвнө, хулганаар 3D хазайна, хэвтээ гүйлгэлтийн хурдаар эргэнэ (rotationY). Дэлгүүрийн зураг (store.webp) = бодит FB зураг; AI-аар студийн гэрэлтэй хувилбар гаргаад зөвхөн гэрэл, өнгийг нь (бага давтамжийн gain map) эх зураг руу шилжүүлсэн — доторх эд зүйл, хээ, бичиг 100% эх зургийнх. Hero stack thumbs = бодит FB зураг.
