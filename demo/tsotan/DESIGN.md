# ЦОТАН (Tsotan Textile) — v2 concept (Nomad Web Studio)
Лавлагаа: хэрэглэгчийн илгээсэн NEXA agency бичлэг — хар хүрээ (bezel), зүүн sidebar дээр босоо лого, дугуй булантай том panel-ууд, pill навигаци, panel-ын буланд "хазагдсан" notch товч, кино мэт hero, хөвөгч объект.
Idea: Цотангийн зураг бүрт байдаг **туузан метр** → sidebar-ын **босоо см шугам** гүйлгэлтийг 0–220 см-ээр хэмжинэ (lerp-ээр зөөлөн, тухайн хэсгийн нэртэй). Hero дээр **шагай** хөвнө (Монгол, Цотан шагайн уут зардаг).
Live thing: бүтээлгийн тооцоолуур (ширээний урт/өргөн → бэлэн 145×220 таарах эсэх, хээ/өнгөтэй SVG, захиалгын мессеж).
Color: --bez #0e1513 (хүрээ) · --bez2 #16201d · --cotton #f4f1ea · --ink #211c18 · --teal #1e5a53 · --clay #b0533a · --ochre #c4922c (үйлдлийн тойрог) · --cobalt #2c4a8f. Өнгөт хэсгүүдийн дэвсгэрийг Higgsfield зургийн дэвсгэрээс авсан: #114040 · #a3412a · #b87e24 · #153884.
Type: Montserrat 800/900 (гарчиг, ТОМ ҮСГЭЭР, giant үгс) · Geologica 300–600 (бичвэр). Ү Ө ₮ шалгасан.
Radius: panel 28px (утсанд 22), карт 20–22, pill 999.
Motion: GSAP 3.12.5 + ScrollTrigger + Lenis 1.1.13 (CDN). Intro: hero clip-path нээгдэнэ, гарчгийн мөр доороос; шагай float + хулганы parallax; hero бичлэг scroll-оор томорно; statement үг бүр scrub-аар тодорно; 4 өнгөт scene sticky-гээр давхарлана (өмнөх нь .92 болж бараана), giant үг хэвтээ гүйнэ; бүтээгдэхүүний галерей pin + хэвтээ scrub (desktop), утсанд scroll-snap. GSAP ачаалагдахгүй эсвэл reduced-motion үед бүх агуулга хөдөлгөөнгүй харагдана (CSS-ээр юу ч нуухгүй).
Images: Higgsfield gpt_image_2_5 — hero (хийсэж буй хээтэй даавуу), 4 студийн зураг (тавцан + өнгөт дэвсгэр), шагай (цагаан дэвсгэрээс өөрсдөө тайрсан); kling3_0 pro 10s hero бичлэг (start=end → тасралтгүй давталт). Бүтээгдэхүүний галерей, захиалгат ажил, дэлгүүрийн зураг = бодит FB/захиалагчийн зураг.
