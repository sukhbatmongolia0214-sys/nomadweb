# Turquoise Home Studio — concept v3 (Nomad Web Studio)

Subject inventory: Кинг Тауэр 147-р байр (ХУД 17-р хороо, Кинг спорт комплексийн урд) · логоны дүүжин гэрэл · өөрсдийн 2 bone china коллекц: **Royal Ware** (Монгол гэрийн тооны дүрслэл, гал улаан, 20ш · 1,468,000→1,321,000₮) ба **Celeste** (цэлмэг тэнгэрийн цэнхэр + платинум хүрээ, 17ш · 1,149,000₮) · "аяга тавгийг дээш харсан сав гэж бэлгэддэг" ёс · Туркийн Madame Coco · Тенсел + Tussah silk хөнжил · Mulberry silk 22mm · 100% хөвөн алчуур · Storepay, хүргэлт · 10:00–19:00 · 9900-7901.

Idea: **тавагны амсар бол хүрээ.** Сайтын бүх зураг тавагны амсартай дугуй хүрээнд (цагаан амсар + алтан зураас + дотор сүүдэр), брэнд нь хоёр коллекцоороо (Royal Ware ↔ Celeste) бүх өнгө, бичгийг удирдана.

Copy rule: зөвхөн захиалагчийн FB/IG дээр бичсэн уриа, тайлбар (Modern décor • Cozy living • Timeless style · Минимал дизайн, дулаан уур амьсгал, тайван мэдрэмж · Timeless Elegance, Crafted for Your Table · Sleep in Luxury · #Skinfriendly …). Зохиомол уриа бичихгүй.

Live thing: **Ширээ засагч** — коллекц + зочдын тоо → дээрээс харсан ширээ, сет, нийт үнэ, сагс.

## Type
- Display: **EB Garamond** 400/500/600 + italic (гарчиг, үнэ) — Cormorant-ийн кирилл «л» Λ хэлбэртэй байсан тул сольсон
- Script: **Pinyon Script** (зөвхөн латин: Royal Ware, Celeste, Tableware, Sleep in Luxury…)
- Body/UI: **Commissioner** 300–600; жижиг label 12px uppercase .13–.24em
- Ү Ө ₮ шалгасан, self-host (fonts/, unicode-range subset)

## Theme
- Light (default) ба dark горим: header-ийн сар/нар товч, localStorage `tq-theme`. Бүх өнгө CSS token-оор ([data-theme=dark] доор дахин тодорхойлсон). Hero бичлэг хоёр горимд ижил.

## Layout (v4)
- Hero: нэг static камертай бичлэг; гарчиг EB Garamond 400, зааны ясан (#FFF9F0) өнгө, дээд caption champagne (#F1E2BF) — гурван мөр бүгд нэг хэв маяг
- Коллекц: pin хийгдсэн бүтэн дэлгэц, хулганы дугуйгаар гүйлгэхэд 3 тавагны загвар солигдоно (Royal Ware → Celeste → Lace), гүйлгэлттэй уялдаж таваг эргэнэ, хоёр чиглэлд ажиллана; баруун талд 01–03 навигаци
- Өрөөнүүд (desktop): нэг дугуй хүрээ байрандаа эргэлдэж (алтан хуваарьт цагираг scroll-оор эргэнэ), дотор нь дараагийн өрөөний зураг дугуйгаар нээгдэн гарч ирнэ; өнгө, текст, cutout объект хамт солигдоно (scrub, хоёр чиглэл). Утсан дээр өрөө бүр тусдаа, зураг нь scroll-оор эргэнэ
- Шинэ ирэлт: pin байхгүй — хулгана дагаж хэвтээ хөдөлнө, дугуйгаар доошоо гүйлгэнэ; бараа бүр тавагны амсартай дискэн дээрээс 3D-ээр "гарч" ирнэ (Higgsfield cutout), дээр нь дарахад дэлгэрэнгүй цонх (зураг + луп, тайлбар, хэмжээ, тоо, сагс, шууд авах)
- Ширээ засагч: 3 коллекц (Royal Ware / Celeste / Lace) + 2·4·6·8 хурдан сонголт + ±; таваг шинэ байрлал руу гулсаж, коллекц солиход эргэж солигдоно, 6-аас олон бол ширээ зууван болно
- Манай хаяг: дэлгүүрийн тод зураг (upscale), дугуй зургууд дээр дарахад байршлын бичлэг, газрын зураг дээр дарахад Google Maps нээгдэнэ
- Дээшээ буцах товч: жижиг таваг, алтан хүрээ нь гүйлгэсэн хувийг харуулна
- Төлбөр (урьдчилан бэлдсэн, демо): Сагс → Мэдээлэл → QPay нэхэмжлэх (QR, банкны товч, хугацаа, "Төлбөр шалгах") эсвэл Storepay хүсэлт → Баталгаажлаа. `PAY.create / PAY.check`-ийг бодит серверийн функцээр солиход ажиллана (QPay callback-д шууд итгэхгүй, payment/check-ээр шалгана)
